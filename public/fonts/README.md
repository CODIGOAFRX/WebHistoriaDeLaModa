# Fuentes tipográficas

La web sirve localmente las variantes latinas de **Cormorant Garamond** y
**Manrope**. Ambas familias se distribuyen bajo la SIL Open Font License y se
obtuvieron del catálogo de Google Fonts.

El texto íntegro de la licencia y los avisos de copyright se incluyen en
`OFL.txt`.

- https://fonts.google.com/specimen/Cormorant+Garamond
- https://fonts.google.com/specimen/Manrope

Mantener estos archivos dentro de `public/fonts` evita dependencias externas y
garantiza que el build no incruste rutas del equipo donde se compila.
